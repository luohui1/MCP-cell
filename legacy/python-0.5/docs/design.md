# MCP-first workspace · 0.5

普通浏览器打开，尊重现有窗口尺寸。不查找 Chrome/Edge 可执行文件，不传 --app 或 --window-size。页面使用当前视口，不设 960px 上限，不强行全屏或接管系统窗口。

MCP 管理是唯一默认主界面。来源侧栏保留 AI 图标、名称、配置绑定数量；中间是服务列表和接入操作。检测已有 MCP 是按钮，额外检测范围与 Agent 程序收纳通过辅助视图进入。没有常驻功能页签。

多 Agent 会话功能保留，用一个选择器切换；从终端返回 MCP 不结束后台会话。终端内提供重命名、Ctrl+C、结束和关闭。选择器只在有会话时出现；最后一个会话关闭后回到 MCP。切换不启动进程，不重放输入。

外层圆角 0；主要按钮、选择器、来源选项 4px；Agent 小卡片 6px；对话框 8px。撤掉悬浮外壳、阴影与大面积玻璃装饰；保留品牌图标用于识别，不让它们占据主任务。

默认界面没有 role=tab 元素或 session-strip。筛选使用普通选择器；保留键盘焦点与原有确认步骤。390px 下来源栏只保留有标签的图标，主列表自行滚动，不挤出页面。

本轮同时修正来源作用域：先按所选客户端收窄分组成员，再生成接入、暂停、还原及批量动作。显示归并不是权限归并，更不是运行复用。
