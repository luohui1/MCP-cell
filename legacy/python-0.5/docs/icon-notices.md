# Icon provenance · 0.4

Identification only; names and marks belong to their respective owners. No affiliation or endorsement is implied. Adding a logo does not mean that its product is installed, authenticated or fully integrated.

The following vector paths are derived from `lobehub/lobe-icons`, commit `8a1b2821bb768c484fe8da20c5e1838b6bf551a9`, `packages/static-svg/icons/`:

- claude-color.svg, openai.svg, gemini-color.svg, opencode.svg
- githubcopilot.svg, cursor.svg, windsurf.svg, cline.svg, kiro.svg

Source: https://github.com/lobehub/lobe-icons/tree/8a1b2821bb768c484fe8da20c5e1838b6bf551a9/packages/static-svg/icons

Adaptations: extract path geometry into a local JS map; remove external sizing/title wrappers; merge equivalent Cline paths; namespace Gemini gradient IDs for each occurrence. Geometry and brand colors of these nine marks are otherwise preserved. No font assets or external resources are included.

Pi uses an original pi glyph, not Inflection's Pi-chat logo. Droid, Aider, Goose, CCS, VS Code and Roo use locally drawn identifying pictograms; these are not claimed as verified official assets. Unknown custom tools use a generic cube. All cards retain visible product names; status is expressed with text as well as dots.
